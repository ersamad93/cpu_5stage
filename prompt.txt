Prompt: 5-Stage Pipelined MIPS Core Generation
Objective: Generate a synthesizable Verilog implementation of a 5-stage pipelined CPU core.

1. RTL Architecture Requirements:

Pipeline Stages: Implement five distinct stages: IF (Instruction Fetch), ID (Instruction Decode), EX (Execute), MEM (Memory Access), and WB (Write Back).

Interfaces: * Standard clk and rst inputs.

			* Instruction memory interface (Program Counter Address out, Instruction in).

			* Data memory interface (Address out, Write-Data out, Read-Data in, Write-Enable out).
			
The register file must be implemented as a 32-element array named `rf` (e.g. `reg [31:0] rf [0:31]`) so that tests can pre-load and read registers.
Reset Logic: Ensure all pipeline registers and the Register File (32 entries) are explicitly initialized to zero on a synchronous reset to prevent X propagation in simulation.
One Instruction per Cycle for Current PC
